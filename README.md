# AERIS 空中交通智能管理大屏

基于课程 PPT 的本地交互原型，展示「AI 监测 → AI 预测 → AI 推荐 → 管制员审核 → 系统执行 → 异常接管」。原生 HTML / CSS / JavaScript，无第三方运行依赖，不连接外部服务。

## 启动

使用 Node.js 20 或更高版本，在 VS Code 终端运行：

```sh
npm start
```

浏览器访问 http://127.0.0.1:4173。更换端口：`PORT=4180 npm start`。

## 演示顺序

1. 默认进入雷暴扰动场景，可切换常态运行、高峰流量；场景切换会重置当前模拟状态。
2. 点击地图上的飞机查看预设航班详情；航迹、气象、扇区图层可分别开关。
3. 在 AI 决策建议中选择方案 A 或 B，展开推荐依据，审核后才会模拟执行。点击驳回不会执行。
4. 执行持续 8 秒，完成后更新预设指标；暂停推演同时暂停模拟执行计时。
5. 执行途中点击异常接管并确认，立即冻结推演并中断执行。恢复辅助模式后，必须重新审核中断的方案。
6. 完成或驳回后可重新生成建议；重置会恢复场景初始指标，审计记录保留于本次页面会话。

## 文件

- `index.html`：大屏布局与界面结构。
- `styles.css`：深色主题、响应式布局。
- `app.js`：SVG 示意地图、预测图、交互及会话日志。
- `simulation.js`：预设场景与纯函数状态转换。
- `server.js`：仅监听本机地址的静态预览服务，仅开放界面所需文件。

## 校验

```sh
npm test
```

验证审核门控、暂停、执行完成、驳回、人工接管与恢复。页面日志仅存内存，刷新后清空，不是持久化或合规审计。

## 使用边界

这是课程展示原型，不是空管运行软件。航迹、空域、机场相对位置、天气、需求与容量、置信度、收益及风险全为示意或预设值；地图不可导航。没有调用 AI 模型，也没有实现真实预测、优化、安全间隔校验、管制指令或外部系统执行。模拟指标不能作为真实效能评价结论。
